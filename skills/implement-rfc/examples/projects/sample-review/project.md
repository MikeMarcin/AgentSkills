# SampleReview context example

Example facts accompany project.json; copy neither file without adapting identity,
paths, ownership and actual repository instructions. Consumer context lives under
.mask/skill-config/implement-rfc, never inside a managed skill.

SRV uses index-ordered RFCs, one issue counter, and the common flat lanes.
The core decides, the host performs, and Qt presents. Read root/nearest AGENTS,
README, CONTRIBUTING, the selected live RFC and card. Keep effects out of core
and widgets. Use designated safe fixtures for external effects.

Run focused acceptance checks for ordinary slices. At pack/milestone integration,
select one relevant broader pass and critical review when scope/risk warrant.
Do not repeat unrelated product builds for workflow metadata changes. An explicit
human criterion stays pending until its real verdict; shared attended-review
provides preparation and local HTML, with wizard for required manual steps.

The shared card/schema and role policy are authoritative. Repository addenda
contain ownership/hazards, not per-project model overrides. Preserve all unrelated
changes and commit only intentional paths. No push/publication is implied.
