# Native recipe

The primary delivers the authorized task and common engineering/bookkeeping contract.
For native-astra-ultra, request Astra Ultra. Native behavior owns whether to delegate,
partitioning, contexts and child routes. Zero children is a valid native outcome.
Use normal built-in capabilities; this path adds no outer coordinator, RFC custom-role
policy, worker quota, prescribed pipeline or mandatory context renewal.

Use `workflow_preflight.py --repo-root ROOT --strategy native` for selected core
readiness. The primary binds/checks milestones with `milestone_checkpoint.py` and
records native lifecycle observations rather than custom dispatch/return receipts.
Preserve safe writer ownership and reconcile actual effects before continuation or
candidate freeze. Unknown child lifecycle remains unknown until accounted for.

Before a new session, read [Scoped host controls](../strategy-host-controls.md).
Inspect project/user/plugin instructions, custom agents and inherited child-route
defaults for treatment leakage. Use supported task-scoped settings or an isolated
task environment; preserve project correctness, permissions and global configuration.
If exclusion cannot be established, record contamination/uncertainty. A Max request
plus hand-written role orchestration is not a substitute for native Ultra.

Keep requested, effective and observed routes separate. Native routes may remain
system-owned and unobservable. Use existing usage capture/reporting; retain partial
coverage and inclusive counter semantics, including visible children already included
in totals. Record recoveries and deviations. Independent review remains independent.
