# Direct recipe

The primary owns design, product edits, tests, self-review, evidence judgment and
permitted bookkeeping under the shared engineering contract. Keep model delegation
disabled through supported scoped host controls; shell/companion/remote model calls
are also delegation. Ordinary deterministic commands and test subprocesses remain
available. Record unavailable enforcement honestly; no global settings are changed.

Run selected readiness with `workflow_preflight.py --repo-root ROOT --strategy direct`
(add `--mode personal` only for storage). The explicit direct-astra-max preset requests
Astra Max; generic direct preserves an explicitly bound primary route. A request or
rendered configuration is not evidence of serving. For scoped host configuration,
read [Host controls](../strategy-host-controls.md) when preparing a new session.

Discover/adopt the authored plan, claim eligible work, then use
`milestone_checkpoint.py bind --repo-root ROOT --target ID --selection FILE --run-id ID
--segment-id ID --mandate-revision ID` to capture the primary's current binding.
Save stdout in the existing continuation location. `check` compares a checkpoint and
current observation with live requirements and explicit execution state. It uses
common obligation/exit checks without child, producer or dispatch identities.

Continue the milestone in this session, including corrections and useful compaction.
For genuine interruption, recover the same selection, current candidate and outstanding
obligations. Record replacement sessions and effects; do not call recovery an
uninterrupted result. Required independent review is external to this implementation
session and stays pending until supplied. A milestone never forces a new session.

Before changing strategy, quiesce/account for writers and commands, preserve the old
checkpoint, and record a new segment with the changed selection and reason. A changed
recipe fingerprint requires reconciliation, not silently accepting the new bytes.
