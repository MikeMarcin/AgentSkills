# Native coordination boundary

The interactive coordinator retains the exact user mandate and assigns one
engineering integrator for the current milestone. The designated integrator owns
engineering acceptance, scoped source changes, board updates and commits within
its authorized repository/branch. Main-only authority stays on main; ordinary
workers and reviewers cannot claim that authority. Never run a second writer
against the same assigned scope.

Bind the run, dispatch, native producer, mandate revision and milestone before
consuming a return. Resolve the integrator model and effort together through the
renderer’s explicit or preserved-engineering route before selecting a coordinator
route. Generated requests are not observations of the serving model.

A completed milestone returns the actual candidate, current live closeout pointer,
evidence references, required pending work and ownership state. Account for the
producer, descendants and commands using native runtime observations; a message
alone does not prove they stopped. A current-milestone correction renews the
assignment to the same native integrator with a new dispatch identity. A safely
completed milestone starts a fresh native integrator without copied history.
The new assignment carries the relevant invariants and live evidence pointers.

`coordinator_handoff.py` provides optional pure structural/control checks through
`validate_return` and `continuation`. It launches nothing and evaluates no
engineering acceptance. Keep consumed dispatch identities in the existing private
run memo. A timeout continues waiting; stale/duplicate events authorize no work.
Unknown ownership requires reconciliation. User cancellation stops continuation.
Required human/native work stays pending. Only a qualified no-grandchildren review
relay may dispatch one integrator-selected independent reviewer and then resume
the same integrator for judgment.

When the integrator cannot spawn ordinary leaf roles, keep implementation and
verification local to that integrator. Use the coordinator only for the qualified
independent-review relay; unavailable required review remains pending.

Use the existing native interactive host and its wait/resume tools. No companion,
headless CLI, API supervisor, permission bypass, or global low-effort setting is
part of this path. Runtime qualification is recorded separately from these source
contract checks.
