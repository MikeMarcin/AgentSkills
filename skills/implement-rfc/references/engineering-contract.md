# Shared engineering contract

Contract ID: `implement-rfc.engineering.v1`.

The authorized engineering owner preserves delivery obligations independently of
execution topology. Role names confer no repository, publication or permission rights.

1. **Orient.** Resolve source, tracker, runtime roots and branch authority through
   `project_config.py`. Read applicable consumer instructions, selected live RFC/cards
   and current closeout. Recover immutable RFC_BASE_SHA, prior evidence and the exact
   user mandate/amendments. Reconcile existing writers and uncertain command effects
   before mutation; preserve unrelated work. Import/allocation follows
   [Pack lifecycle](pack-lifecycle.md) only with main/tracker authority.
2. **Bind.** Use [Plan-first execution](milestone-plans.md) to discover/adopt authored
   grouping, outcomes and exits. Claim eligible cards using [Bookkeeping](bookkeeping.md)
   before product edits. Continue constituent work inside the milestone; cards and
   commits are progress. Preserve external dependencies and source/path ownership.
3. **Engineer.** Design, implement and test within the selected recipe's edit authority.
   Run focused direct checks of the public behavior, inspect touched code for simple
   maintainable structure, and retain actual failures and useful evidence. Before an
   interruption, refresh the current frontier on the existing closeout: candidate,
   paths, diagnosis, checks, commands/owners, remaining obligations and next step.
4. **Accept.** Apply [Verification and closeout](verification-and-closeout.md): the
   authorized owner judges all bound obligations/exits against real evidence. Required
   independent/native/human acceptance cannot be self-certified, erased by a strategy
   or substituted by fixture success. Explicit owner changes to acceptance are recorded
   as amendments, separately from observations. Finish eligible work with evidence and
   explicit-path commits through the existing board/personal commit guards.
5. **Continue.** Account for task-owned commands and writers before candidate freeze,
   topology change or ownership transfer. Preserve unfinished work and pending decisions
   with their exact candidates. Same-session progress needs no synthetic dispatch.
   Respect the user's stop boundary and record the next eligible scope. Final RFC/pack
   acceptance requires the actual full selected criteria, not merely a context ending.

Project and personal storage retain the same authority: paired source/tracker lanes,
claim/finish guards and private runtime evidence stay with their existing helpers.
Detailed dispatch identities, agent turnover and leaf economics belong only to their
recipe. Common helpers check logical consistency; they never certify evidence truth.
