# Public source preview

This preparation covers the canonical skill library, local helper code, contributor
checks and documented MASK installation paths. It does not change repository
visibility or install into real consumers. Push and final cross-repository checks
are handled by the release coordinator after both source candidates are ready.

The library has no stable release/support matrix. Optional remote stations,
provider routes, native driver loading and model experiments are experimental.
Fixture success verifies local helper behavior; it does not establish native
policy enforcement, model loading, overnight reliability or subscription savings.

## Verification entrypoints

[CONTRIBUTING.md](../../CONTRIBUTING.md) gives the environment setup and complete
offline test command. jsonschema is required for the published schemas. Companion
checks select a local ManageAgentSkills checkout explicitly and use disposable
projects and local bare remotes. They do not edit a real registry, contact hosted
models or exercise a live consumer migration.

CI runs the self-contained Linux/Python 3.11 checks while this repository is
private. Once public, its workflow requires the public MASK checkout and the
composed CLI/bundle/import checks. A dependency checkout failure is a failure,
not an undisclosed skip. The initial GitHub run and unavailable native-platform
acceptance are distinct from local verification evidence.

## Privacy and evidence

The current mutable documentation replaces avoidable real user-home paths,
machine names, remote-control host IDs and native session identities with explicit
`EXAMPLE` or `REDACTED-SESSION` values. Correlated session placeholders preserve
chronology without exposing the original identifiers. Git revisions, test results,
limitations and meaningful scope remain. Protocol identifiers such as
`aito.implement-rfc.remote-station.v2` remain literal for compatibility.

Sanitized runtime records are historical evidence projections, not replayable
unchanged checkpoints. Existing fingerprints and receipts refer to the originally
recorded inputs; privacy editing does not recertify those old runs. Exact current
execution checkpoints remain in ignored/private runtime storage.

Immutable imported packets and Git history were preserved. Current cleanup does
not erase earlier metadata from commits or retained archives. The final release
audit reports remaining historical exposure separately; no history rewriting is
authorized by this source preparation.

The [provenance record](skill-provenance.md) identifies imports and known adapted
sources. Author-rfc, grill-rfc and grill-me retain Matt Pocock's MIT licenses;
writing-for-agents retains the complete notice in its package README. The original
frontend-design package contains no upstream payload. License selection for this
repository must preserve these notices and the recorded origin of older imports.
