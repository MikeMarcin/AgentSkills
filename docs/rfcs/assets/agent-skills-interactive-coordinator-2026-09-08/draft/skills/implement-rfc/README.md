# Editorial candidates, not a deployed skill

These files specify the proposed runtime behavior. During implementation, reconcile
with live helper contracts, role generation and consumer instructions. This is not
a full package replacement: existing scripts, config, schemas and qualified branch
references remain in the source and are deliberately not copied here.

Every Markdown target inside this draft tree exists here. References written as
code paths name existing installed files to consult only for their stated branch.
Those files are listed in the packet CHANGE_MAP.md and SOURCE_BASIS.md. The draft
has one public SKILL.md; subordinate references are not independently discovered
skills. No host-specific activation metadata is included.

Scope/authority in the RFC is normative. A necessary editorial change during
implementation must preserve that behavior and be verified through the workflow
cases rather than accepted from word counts alone.
