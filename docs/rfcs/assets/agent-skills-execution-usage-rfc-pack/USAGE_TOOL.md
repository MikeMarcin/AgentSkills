# Bundled collector: run now or integrate into the skill

## Run the supplied seed now

Use Python 3.11 or later. The seed has no third-party Python dependencies. Git is
needed for implicit Git-root discovery; MASK is needed only for `--mask-projects`.
It is not necessary to copy the seed into a project to use it.

Change to the project to measure and invoke the **absolute path** to the extracted
packet's `payload/skills/implement-rfc/scripts/usage.py`:

```sh
python3 /path/to/agent-skills-execution-usage-rfc-pack/payload/skills/implement-rfc/scripts/usage.py
```

The script location is deliberately irrelevant to project selection. Using the
packet's own directory as cwd measures that directory only if it is itself a valid
project; it does not magically select your consuming project.

## After canonical adoption and selected MASK deployment

From a project root:

```sh
python3 .agents/skills/implement-rfc/scripts/usage.py
python3 .agents/skills/implement-rfc/scripts/usage.py --mask-projects --days 30
```

On Windows, use the installed `py -3` or `python` and the same script/flags. The
normal `mask.cmd` generated by the supplied MASK implementation is recognized
without evaluating batch syntax. Custom wrappers can use
`--mask-python-entrypoint C:\path\ManageAgentSkills\mask.py`. Native Windows
execution remains a qualification task; a portable parsing fixture is not that proof.

The default is the invoking physical project/worktree, seven days, both local
provider histories, and a new ZIP under the platform's user-local
`implement-rfc/usage/captures` directory. Cwd and explicit scope can add
`--include-worktrees`. `--mask-projects` already selects each registered physical
project/worktree independently and cannot be combined with that expansion flag.
It excludes MASK personal scope and remote machines. Run once per device for a
multi-machine comparison, using distinct `--machine` labels.

Useful examples:

```sh
python3 .agents/skills/implement-rfc/scripts/usage.py --dry-run
python3 .agents/skills/implement-rfc/scripts/usage.py --mask-projects --dry-run
python3 .agents/skills/implement-rfc/scripts/usage.py --mask-projects --days 30 --machine mac-main --out ~/Desktop/rfc-usage-mac-main.zip
python3 .agents/skills/implement-rfc/scripts/usage.py --project Demo=/work/demo --since 2026-09-01T00:00:00-07:00 --json
```

Date-only `--since 2026-09-01` means UTC; timestamps with offsets avoid ambiguity.
`--until` is exclusive. Existing output files are refused. A missing/unavailable
provider or project never becomes a zero-usage assertion. `--strict` returns 3 on a
usable partial/empty archive. The default still produces that archive and prints
its coverage warnings. `--json` puts the final summary on stdout and progress on
stderr. No collector mode uploads files.

## Quota snapshots are separate and explicit

Ordinary `usage.py` remains offline. It imports already saved snapshots with
`--quota-dir DIRECTORY`; it does not implicitly start a provider CLI. To make an
explicit current Codex account observation:

```sh
python3 .agents/skills/implement-rfc/scripts/usage_quota.py codex --account-label codex-main --machine mac-main --out-dir ~/rfc-quota
python3 .agents/skills/implement-rfc/scripts/usage.py --mask-projects --quota-dir ~/rfc-quota
```

The quota command starts the installed app server and requests account limits. It
makes no model turn, credit purchase or reset-redemption call. It can contact the
provider through the native CLI; permission/auth/runtime availability are explicit
requirements. Existing Claude status-line integrations may pipe their **native JSON**
to `usage_quota.py claude-stdin`; do not paste an arbitrary prose `/usage` display.
Manual mode is available through `--help`. No hooks are installed by these commands.

## What to attach

Inspect the ZIP's SUMMARY.md and manifest, then attach that ZIP. It contains
allowlisted metadata, not raw transcripts/source/commands or credentials. It still
contains identifying timestamps, project labels and stable hashes; this is not
anonymization. `--include-task-text` is an explicit sensitive opt-in and unnecessary
for routine accounting. Do not commit private live capture archives to AgentSkills.

## Present limits of the code seed

The seed is runnable and fixture-tested. It does not implement the runner or the
new reconciled usage report. Large files stream, but some dedup/session indexes are
still in memory; production bounded indexing is assigned to ASK-0023. Version-specific
provider fields may be unsupported and recorded as gaps. Embedded `exec` source is
not evaluated to identify hidden operations. Native macOS/Windows and real MASK
installations have not been exercised in this packet build. No quality or quota
saving is claimed. The RFCs and cards define the remaining acceptance work.
