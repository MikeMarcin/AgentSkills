## Instruction-writing application

Keep a short mandatory action before implementation dispatch: resolve and bind the
plan; when absent, assign preparation and engineering to the first integrator.
Store the shared detailed contract once, reached for import/normalization/formation/
amendment operations. The ordinary current-milestone assignment carries only its
projection. Co-locate completion with remaining obligations and continuation; do
not leave the old unconditional fresh rule next to a new exception paragraph.

Native role entrypoints must agree with canonical instructions. Reachability tests
check links and applicable branches, while native qualification checks behavior.
Measure actual common reading paths rather than claiming progress from a shortened
SKILL.md that requires several new mandatory manuals. No special hidden instruction
waiver or reduction in required verification is an optimization.
