Implement [RFC-DEMO-0001](RFC-DEMO-0001.md) and its six issues. The supplied
[milestone-plan.json](milestone-plan.json) is the execution plan.

can be chosen by the integrator; standard-library Python is sufficient.

provisional fixture IDs and may need remapping in the selected disposable consumer.
