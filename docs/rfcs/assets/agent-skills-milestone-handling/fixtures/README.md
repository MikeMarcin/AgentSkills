# Raw acceptance inputs

`raw-pack/` is a small authored six-card, two-milestone target. Feed its README and
unprepared source documents through the real installed skill; do not pre-adopt its
plan or inject the desired continuation answer into the test prompt.

`legacy/IMPLEMENTATION_ORDER.md` replaces that JSON for a legacy case. `planless/`
is a later small ad-hoc target. `partial/` represents a large card with explicit
criterion subsets and required unplanned remainder. `scenarios.json` records the
wider negative/continuation cases and required evidence types, not test results.

These fixture issue headings deliberately exercise ambiguous ordinary authoring.
They are not live AgentSkills cards and must never be imported into the real board.
