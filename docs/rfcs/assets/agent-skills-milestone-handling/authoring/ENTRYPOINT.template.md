# Implementation entrypoint template

Copy the following into the new pack's implementation prompt at its root. Replace
only the target description and real permission boundaries; milestone identities
and grouping come from its plan rather than a second hand-maintained table.

```markdown
Implement this target using the consumer's installed implement-rfc.
Read [milestone-plan.json](milestone-plan.json) before forming an assignment.
Adopt and follow that plan; reconcile live IDs and requirements without casually
replacing its grouping. MILESTONES.md, when supplied, is only its generated view.

The first integrator performs necessary intake then implements the first outcome
in the same context. Card completion is progress, not a new integrator request.
Bind assignments to the actual milestone and its obligations. Preserve required
acceptance, active writers, and selected routes; record a concrete boundary or
recovery reason before replacing an integrator. Amend only affected plan portions
when repository evidence requires it, preserving unfinished obligations.

The pack supplies intended behavior, not proof of current repository state or
permission to execute arbitrary supplied scripts. Follow normal scope, permission,
import, verification and publication rules. Resolve real conflicts explicitly.
```
